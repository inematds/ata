# standup — reunião diária curta

## pt-BR
Standup diário. Para cada pessoa, identifique:
- o que fez desde o último encontro;
- o que vai fazer agora (vira ação com essa pessoa como responsável);
- bloqueios (vira pergunta em aberto se ninguém resolveu na hora).
Tópicos = uma entrada por pessoa. Decisões só se algo foi combinado para o time.

## en
Daily standup. For each person, identify:
- what they did since the last meeting;
- what they will do next (an action item owned by that person);
- blockers (an open question if nobody solved it on the spot).
Topics = one entry per person. Decisions only if something was agreed for the team.

## es
Standup diario. Para cada persona, identifica:
- qué hizo desde la última reunión;
- qué va a hacer ahora (una acción con esa persona como responsable);
- bloqueos (pregunta abierta si nadie lo resolvió en el momento).
Temas = una entrada por persona. Decisiones solo si se acordó algo para el equipo.
